## 一、怎么开手机视图（不用真手机也行）

1. 打开网站，按 **F12**
2. 点左上角那个 **手机/平板小图标**（或按 `Ctrl + Shift + M`）
3. 顶部选设备，建议至少测这 **4 档**：

| 档位 | 宽度 | 对应设备 |
|---|---|---|
| 大屏收缩 | 1240px | 笔记本 |
| 平板横屏 | 1080px | iPad 横着拿 |
| 平板竖屏 | 820px | iPad 竖着拿（侧边栏会变成抽屉） |
| **手机** | **375px / 414px** | **iPhone / 安卓主力机型** 🔴 最重要 |

> 💡 代码里实际断点是 1240 / 1080 / **820 / 540**，540 以下会切成单列。
> **重点盯 540px 以下**，那是手机的主要战场。

### 严重程度分级（统一标准）

| 级别 | 含义 | 例子 |
|---|---|---|
| 🔴 **致命** | 功能用不了、点不了、内容看不到 | 提交按钮被挡住、文字溢出屏幕 |
| 🟠 **严重** | 能用但很难受 | 要横向滑动才能看全、按钮太小点不准 |
| 🟡 **一般** | 不好看但不影响使用 | 间距不匀、字号偏小 |
| 🟢 **建议** | 锦上添花 | 动画在小屏上有点卡 |

**修复优先级建议**：先把 🔴 全部干掉，再处理 🟠。

## 四、重点怀疑对象（可以先盯着这几个）

> 根据代码结构预判的，去确认一下是不是真的有问题：

```
□ 候选对比页 —— 那个表格列数多，很可能要在小屏横向滚动（确认能滚、且能看清）
□ 筛选器区域 —— 一堆筛选按钮挤在一行，小屏上可能换行/重叠
□ 新手指引气泡 —— 气泡定位是按坐标算的，小屏上可能指错地方或飞出屏幕
□ 侧边栏抽屉 —— 820px 以下变抽屉，确认能正常打开/关闭，不会卡住
□ 弹窗（登录/注册）—— 小屏上会不会超出屏幕底部，导致按钮点不到
□ 宠物悬浮球 —— 会不会挡住重要按钮
□ 表格 —— 有没有 overflow-x 横向滚动
```
