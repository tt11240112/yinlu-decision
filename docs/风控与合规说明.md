# 第二部分 · 合规（🔴 优先做，这块最重要）

## 2.1 我们收集了哪些用户数据（照实列）

> 依据 `js/18-feature-actions.js` 里的用户对象：

| 数据项 | 是否必填 | 敏感度 | 存储位置 |
|---|---|---|---|
| 昵称 | 否 | 低 | localStorage（→ 未来入库） |
| 邮箱 | **是** | **中** | localStorage（→ 未来入库） |
| 密码（哈希+盐） | **是** | **高** | localStorage（→ 未来入库） |
| 角色（学生/家长） | 是 | 低 | 同上 |
| 阶段（高考/考研/就业） | 是 | 低 | 同上 |

**高敏感红线检查**（🔴 请逐项确认）：

```
□ 我们有没有收集身份证号？ → 必须：没有
□ 我们有没有收集手机号验证码？ → 必须：没有
□ 我们有没有收集真实姓名？ → 必须：没有
□ 我们有没有收集地理位置？ → 必须：没有
□ 有没有涉及未成年人（不满14岁）的专门数据？ → 需说明
```

> ⛔ **如果答案是"有"**，请立刻在群里 @ P1：**这是重大合规问题，必须处理。**

## 2.2 适用的法律法规

> 不用背条文，知道有哪些、我们该注意什么就行。

| 法规 | 跟我们的关系 | 我们要做的 |
|---|---|---|
| 《个人信息保护法》（PIPL） | 我们收集邮箱 = 收集个人信息 | 要有隐私政策、告知用途、允许用户删除 |
| 《网络安全法》 | 网站运营者的安全义务 | 数据加密、日志留存 |
| 《数据安全法》 | 数据处理活动规范 | 分类分级管理 |

## 2.3 我们需要补的东西（🔴 国庆后必做）

| # | 事项 | 状态 |
|---|---|---|
| 1 | **隐私政策页面**（说明收集什么、怎么用、怎么删） | ☐ 未做 → 🔴 上线前必须有 |
| 2 | **用户注销/删除数据的功能** | ☐ 未做 → 🔴 PIPL 要求 |
| 3 | 未成年人保护说明 | ☐ 未做 |
| 4 | 数据加密传输（HTTPS） | ☐ 待部署时处理 |

## 2.4 答辩该怎么说

✅ **推荐口径**：
> "我们严格遵守个人信息保护相关要求：
> **仅收集邮箱等必要信息，不收集身份证、手机号、位置等高敏感数据**；
> 密码采用加盐哈希存储；
> 后续上线前将补充隐私政策与用户数据删除功能。"

❌ **避免**：说"我们完全合规" —— 因为你还没做隐私政策，
说满了反而经不起追问。
