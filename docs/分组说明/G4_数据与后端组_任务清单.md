# 第 9 章 · 前辈踩过的坑

### 坑 1：数据文件一个逗号错了，全站白屏

JS 数组最后一个元素后面**不能有多余的逗号**（部分环境下会报错）。
用 `node --check` 检查，然后**一定要实际打开网页**看。

### 坑 2：学校名称不统一，导致同一个学校出现两次

「福建师范大学」和「福建师范大学(旗山校区)」会被当成两个学校。
**建议统一用教育部公布的官方全称**，校区信息放单独的字段。

### 坑 3：位次和分数搞混

录取位次（自己在全省排第几名）和录取分数（考了多少分）是**两回事**。
搞清楚再录，录错了会很尴尬。

### 坑 4：改了数据文件，忘了同步给 G2

你的数据结构改了，**G2 的渲染函数会读不到东西**。
**改数据结构之前必须在群里 @ 全组说明**，尤其是 @P4 @P5。

### 坑 5：爬数据被封 IP

别用高并发爬虫去爬考试院官网（那是政府网站，别给人家添麻烦）。
**推荐手动下载公开的 Excel/PDF，然后本地脚本解析** —— 稳妥、有来源、不惹事。
