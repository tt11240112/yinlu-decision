## 六、三个最容易踩的坑（全组必知）

1. **`js/26-family-override.js` 覆盖了 3 个函数**
   → `js/16:516` 的 `renderFamily`、`js/18` 的 `generateFamilyInvite` / `joinFamilyInvite`
   都是**死代码**，改了没效果。家庭功能**只改 `js/26`**。

2. **根目录 `index.html` 是自动生成的**
   → 手改会被脚本覆盖。改 HTML 去 `template/index.html`，然后跑 `node tools/build-index.js`。

3. **新增文件后必须跑构建脚本**
   → 不跑 `index.html` 里没有你的文件，**代码根本不加载**，你会以为"写了没效果"。
