```

├── index.html              ← 网站入口（自动生成，别手改）

│   ├── build-index.js        生成 index.html
│   └── build-standalone.js   生成单文件版
```

## 六、三个命令（记住就够）

在 `引路网站_v3/` 目录下：

```bash
# 1. 新增了 js/css 文件，或改了 template/index.html 后
node tools/build-index.js

# 2. 需要演示/发给别人时
node tools/build-standalone.js

# 3. 想验证拆分没问题时
node tools/split-legacy.js
```

**只改已有文件的内容 → 什么都不用跑。**

## 八、三个最容易踩的坑（全组必知）

1. **`js/26-family-override.js` 覆盖了 3 个函数**
   → `js/16:516` 的 `renderFamily`、`js/18` 的 `generateFamilyInvite`/`joinFamilyInvite` 都是**死代码**，改了没效果。家庭功能只改 `js/26`。

2. **根目录 `index.html` 是自动生成的**
   → 手改会被覆盖。要改 HTML 去 `template/index.html`，然后跑 `node tools/build-index.js`。

3. **新增文件后必须跑构建脚本**
   → 不跑的话 `index.html` 里没有你的文件，代码根本不会加载，你会以为"写了没效果"。
