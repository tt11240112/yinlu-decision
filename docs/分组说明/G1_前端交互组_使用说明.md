## 2. 你认领的文件详解

### A 角的文件

#### `js/04-core-utils.js`（13 行，全项目最小）⭐ 地基

**作用**：全站最底层的工具函数，**所有文件都依赖它**。

| 函数 | 用法 | 说明 |
|---|---|---|
| `$("#id")` | 选单个元素 | 找不到返回 `null` |
| `$$(".class")` | 选多个元素 | 返回数组 |
| `read(键, 默认值)` | 读 localStorage | 没值返回默认值 |
| `write(键, 值)` | 写 localStorage | |
| `escapeHtml(文本)` | HTML 转义 | **防 XSS，别改** |

**⚠️ 警告**：`escapeHtml` 在全站被调用 **270+ 次**，是防 XSS 的核心。
**不要改它的逻辑**——改错会引入安全漏洞，而这正是我们参赛要展示的东西。

---

#### `js/08-core-ui.js`（27 行）通用组件

| 函数 | 用法 |
|---|---|
| `showToast("保存成功")` | 右下角弹提示 |
| `openModal("questionModal")` | 打开弹窗 |
| `closeModal("questionModal")` | 关闭弹窗 |

被 **10 个文件调用 60+ 次**，是全站交互反馈最密集的工具。
**改外观去 `css/`，别改这里的逻辑**；改函数签名（参数）会让全站崩。

#### `js/11-core-router.js`（122 行）页面路由 ⭐

**作用**：视图切换（页面路由）+ 回到顶部按钮。

| 函数 | 说明 |
|---|---|
| `switchView(name)` | 切换到某个页面 |
| `updateBackToTopButton` / `scheduleBackToTopUpdate` / `scrollCurrentPageToTop` | 回顶按钮相关 |
| `suppressBackToTopDuringViewChange` | 切换时抑制回顶闪烁 |

**重要变量**：
- `BACK_TO_TOP_VIEWS` —— 哪些页面显示回顶按钮
- `ONBOARDING_STEPS` —— **新手指引的步骤和文案在这里**（改引导文案来这，不在 12 号文件）
- `onboardingIndex`、`onboardingTimer` —— 引导的运行时状态

**怎么加新页面（四步，别漏）**：
1. **`template/index.html`** 里加 `<div class="view" id="view-xxx">…</div>`
   （⚠️ 不是根目录的 index.html，那个是生成的）
2. 同一个文件的导航栏加按钮，或在 `23-events-buttons.js` 绑定
3. 要回顶就把 `"xxx"` 加进 `BACK_TO_TOP_VIEWS`
4. **跑 `node tools/build-index.js`**，否则页面不会出现

> ⚠️ `switchView("home")` 的名字必须和 `<div id="view-home">` 对应，写错就白屏。

#### `js/20-events-click.js`（206 行）全局点击事件委托 ⭐ 最常用

**这是你们最常改的文件**。所有"点一下触发"的行为都在这里。

**模式**：不在每个按钮上绑 `onclick`，而是在 `document` 上统一判断：

```javascript
document.addEventListener("click", (event) => {
  const petAction = event.target.closest("[data-pet-action]");
  if (petAction) { handleCyberPetAction(petAction.dataset.petAction); return; }
  // ... 更多判断
});
```

**怎么加一个新点击行为**：
```javascript
// 1) 在 template/index.html 的元素上加 data- 属性
<button data-my-action="doSomething">点我</button>

// 2) 在 20-events-click.js 里加判断
const myAction = event.target.closest("[data-my-action]");
if (myAction) {
  handleMyAction(myAction.dataset.myAction);
  return;   // ← 记得 return，否则会继续往下匹配
}
```

> ⚠️ **写错 `data-` 属性名不会报错，只会"点了没反应"** —— 这是最常见的坑。
> 排查方法：加一行 `console.log("点到了！")`，F12 看有没有输出。

#### `js/23-events-buttons.js`（152 行）按钮直接绑定

用 `$("#xxx").addEventListener(...)` 直接绑。

## 4. 你这一组还缺什么（本组专属缺口）

这些是**只有前端组能做、且直接决定观感**的事：

### 🔴 最关键：移动端适配（目前几乎没有）

高三学生和家长 **90% 在手机上**。现在这套 CSS 是 PC 思维写的（204KB）。

| 待办 | 说明 |
|---|---|
| **360px 起设计** | 用 F12 手机视图逐个页面走一遍，记录哪些地方挤爆了 |
| **触控友好** | 按钮 ≥44×44px、间距够大、去掉 hover 依赖（手机没有 hover） |
| **卡片横向滚动** | 对比表格在手机上要能横滑，不能挤压 |
| **弹窗适配** | 登录/提问弹窗在小屏上要能滚、能关 |
| **测试机型** | 至少测 iPhone SE（375px）+ 安卓（360px）两种宽度 |

> **验收标准**：用手机浏览器打开 `引路网站_单文件版.html`，能完整走完"浏览→搜索→提问→收藏"。

### 🟠 体验与性能

| 待办 | 说明 |
|---|---|
| **首屏加载** | 现在 CSS 3791 行 + JS 3869 行全量加载。可考虑按需加载或压缩 |
| **滚动性能** | `24-events-keyboard.js` 里 scroll 监听较多，注意节流 |
| **空状态** | 没有数据时的占位图/文案（现在是空白，很难看） |
| **加载状态** | 按钮点击后的 loading 态，避免用户重复点 |
| **错误提示** | 操作失败要有明确反馈，不能静默失败 |
| **无障碍** | 按钮加 `aria-label`，表单加 `label`（评委可能提到，是加分项） |

### 🟡 PWA（可选但很加分）

| 待办 | 说明 |
|---|---|
| `manifest.json` | 让网站能"添加到桌面" |
| Service Worker | 离线可用 |
| 图标 | 192px / 512px 各一张 |

> PWA 体验接近小程序，但**不用过微信审核**。这是我们选网站而非小程序的底气之一。

### 🟡 长期

- 组件化抽取（现在卡片、弹窗的 HTML 都是重复拼的字符串）
- 动画系统统一
