# 第 1 章 · 先回答你刚才问的三个问题

## 问题 1：「每个人的代码在哪？要我单独发给每个人吗？」

### 答：**不用发。让他们自己一次性下载全部代码。**

> **完整答案**：
> 代码**已经全部切分好了，全部放在 GitHub 仓库里了**。
> 队友去 GitHub **下载一次**，就会得到**全部 26 个 JS + 15 个 CSS**，
> 也就是**整个项目的完整代码**。

**为什么不用分开发**：

1. 分开发会很痛苦 —— 他自己拿到的是**零散文件**，**缺了别人的代码根本跑不起来**，
   看不到网页效果，等于没法干活。
2. 网站是所有代码一起加载的，**必须整个项目一起跑**。
3. 分发出去之后，版本就乱了 —— 明天你改了，他手里的那份又旧了。

**所以他要做的是**：下载整个项目 → 然后**只改自己那几个文件**。

> ✅ **你唯一要告诉他的**是：「**你负责的文件是下面这几个**」（对应文档第 1 章的表）。
> **代码他自己拿，地盘你告诉他。**

## 问题 2：「让他直接在 GitHub 里面找吗？」

### 答：**对，但有个坑必须提醒他把分支切到 `v3`。**

GitHub 打开仓库，默认显示的是 **`main` 分支**。
`main` 是很早以前的旧版本（三个大文件堆在一起那个），
**如果他不切换，看到的就是错的旧代码，改了等于白改。**

> ⚠️ **这是最容易翻车的一步**，所以我在每份文档的第 0 章都写了加粗大字：
> **Clone 完之后，把分支从 `main` 切成 `v3`。**

（备注：`main` 分支已经冻结保护，他也推不上去，所以最多是白干，不会污染仓库。）
