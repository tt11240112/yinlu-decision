## 二、逐目录详解

### 📁 `template/` —— HTML 的唯一真源

| 项目 | 内容 |
|---|---|
| **干什么用** | 网站的 HTML 结构。**加页面、改导航、改静态文案、加 `<script>` 一律在这里** |
| **谁能改** | 🟢 **只有 P1**（CODEOWNERS 锁死） |
| **其他人要改怎么办** | 在群里 @P1 说明要改什么，或自己提 PR 让 P1 合并 |

**为什么根目录的 `index.html` 不能改**：
它是由脚本把 `template/index.html` 里的两个占位符替换出来的。
你手改了 index.html，下次任何人跑构建脚本，你的改动**立刻被覆盖，一分不剩**。

```html
<!-- template/index.html 里的两行占位符（别在上面写东西） -->
<script src="./app.js" defer></script>       ← 会被替换成 26 个 js 标签
<link rel="stylesheet" href="styles.css">    ← 会被替换成 15 个 css 标签
```

**改完必跑**：`node tools/build-index.js`

### 📁 `js/` —— 26 个文件，6 层结构

**加载顺序 = 文件名字典序**，这是设计好的，别乱改文件名。

| 层 | 编号 | 文件 | 归属 |
|---|---|---|---|
| **数据** | 01–02 | `01-data-experiences.js` `02-data-institutions.js` | P8 |
| **配置** | 03 | `03-config-constants.js` | **P1** |
| **工具** | 04–05 | `04-core-utils.js`（P2） `05-core-security.js`（P6） | P2 / P6 |
| **功能** | 06–19 | `06-profile` `07-theme` `08-ui` `09-calendar` `10-pet` `11-router` `12-onboarding` `13-filters` `14-picker` `15-render` `16-compare` `17-trust` `18-actions` `19-qa-tab` | P2 / P3 / P4 / P5 / P6 |
| **事件** | 20–24 | `20-click` `21-form` `22-menu` `23-buttons` `24-keyboard` | P2 / P3 / P5 |
| **启动** | 25 | `25-bootstrap.js` | **P1** |
| **覆盖** | 26 | `26-family-override.js` | P6 |

**三条铁律**

1. **26 号最后加载，会覆盖前面的同名函数。**
   所以 `js/16` 里的 `renderFamily`、`js/18` 里的 `generateFamilyInvite` / `joinFamilyInvite`
   都**是死代码，改了没反应**。家庭/邀请码功能只改 `js/26`。

2. **变量是全局共享的**（26 个文件靠 `<script>` 顺序共享作用域，没有 import）。
   → **别随手起全局变量名**。`const data = ...` 这种写法很可能把别人的覆盖掉。
   → 想加全局变量，去 `js/03-config-constants.js` 找 P1 加。

3. **加新文件：直接建 `js/27-xxx.js`**，然后跑构建脚本。
   不用改 index.html，脚本会自动扫到。**文件名必须数字开头**。

**改动后要跑构建吗？**

| 你做了什么 | 要跑吗 |
|---|---|
| 改已有 js 文件的内容 | ❌ 不用 |
| 新建/删除/重命名 js 文件 | ✅ 跑 `node tools/build-index.js` |
| 改了 `template/index.html` | ✅ 跑 |

## 五、新人最容易犯的 5 个错

| # | 错误 | 后果 | 怎么避免 |
|---|---|---|---|
| 1 | 手改根目录 `index.html` | 下次构建，改动**凭空消失** | 改 `template/index.html` |
| 2 | 新建 js 没跑构建 | 页面毫无反应，以为自己写错了 | 建完立刻跑 build-index.js |
| 3 | 改了 `js/16` 的家庭函数 | 没效果（被 26 号覆盖） | 家庭功能只改 `js/26` |
| 4 | 起了全局变量名如 `data` `list` | 悄悄覆盖别人的变量，**很难查** | 用前缀，或找 P1 加到 03 号文件 |
| 5 | 在 `v3` 分支上直接写 | 违反分支保护，PR 被拦 | 先 Create branch |

## 六、一句话记住

> **`template/` 是 HTML 的家，`js/` `css/` 是代码，`tools/` 是生成器，
> 根目录的 `index.html` 只是产物——手改它，等于在打印出来的纸上改 Word。**
