## Step 4 · 把默认分支改成 v3（3 分钟，很重要）

**为什么必须做**：不做这步，队友 clone 下来拿到的是 `main`（8 月那版旧东西，14 个文件），
他们会以为你给错代码了。改了之后，队友 clone 就直接是新版。

1. 仓库页面 → 右上角 **Settings**
2. 左侧菜单点 **Branches**
3. 在 **Default branch** 那一栏，右边点 **Switch to another branch**（双向箭头图标）
4. 下拉选 **`v3`**
5. 点 **Update**
6. 弹窗警告说"这会影响……" → 勾选 **I understand**，再点 **Update**

> ⚠️ 这一步**完全不影响**已经存在的任何东西，只是改一个"新人默认下载哪个"的设置。

## Step 5 · 给 v3 上锁（3 分钟，最重要的一步）

**做完这步，就再也不会出现"某个人直接把代码推歪、全站崩掉"的情况。**

1. 还在 **Settings** → **Branches** 页面
2. 右边 **Add branch ruleset**（如果是新版界面）
   或者 **Add classic branch rule**（如果是旧版界面）
   —— **两个看到哪个点哪个，作用一样**
3. 按下面填：

| 项目 | 填什么 |
|---|---|
| Ruleset name / Branch name pattern | `v3` |
| Enforcement status | **Active** |

4. 往下找，勾选这几项：

| 勾这个 ✅ | 作用 |
|---|---|
| **Require a pull request before merging** | 任何人不能直接改 v3，必须提 PR |
| → Required approvals 填 **`1`** | 至少 1 个人点头才能合 |
| **Dismiss stale pull request approvals** | 代码改了之后，原来的同意作废，重新审 |
| **Require review from Code Owners** | ⭐ **关键**：改谁的文件，就必须谁同意 |

5. ⚠️ **不要勾** `Require status checks`（我们还没配自动测试，勾了会卡死所有人）
6. 最下面点 **Create**

> "Require review from Code Owners" 这一项，配合我给你写的 `.github/CODEOWNERS` 文件，
> 就是**防止再出"一个人闷头合并"的那个开关**。
