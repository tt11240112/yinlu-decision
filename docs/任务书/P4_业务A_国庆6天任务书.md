## 六、怎么提交到 GitHub

同 P2 / P3，**两条路线**（详见 `docs/17`）：

**Desktop 路线**（有电脑时用这个）：
```
Branch → New branch
分支名：feat/p4-filters-筛选修复
→ 改 js/13 14 15 或 css/03 09
→ Summary 填：fix(filters): 修复筛选结果为空时的显示
→ Commit to 分支名
→ Publish branch
→ 网页黄色提示条 → Compare & pull request
→ 标题照填，勾选 7 条自检 → Create pull request
（系统自动把 P5 加为审核人）
```

**网页路线**（国庆在外时）：
```
github.com → 确认分支是 v3
→ 找到 js/13-feature-filters.js
→ 点铅笔图标 → 改
→ 拉到最下面选 Create a new branch...
→ Propose changes → Create pull request
```

> 🔴 **改了 `css/03` 或 `css/09` 之后不用跑构建**（只是改内容）。
> **但如果你新建了 css 文件，必须跑 `node tools/build-index.js`**，否则不生效。
