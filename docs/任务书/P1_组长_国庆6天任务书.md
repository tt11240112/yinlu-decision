## 六、怎么提交到 GitHub

你改的是文档和配置，走标准流程：

```bash
# 1. 切分支（永远不要在 v3 上直接改）
git checkout -b feat/p1-申报书初稿

# 2. 改文件……

# 3. 如果新建了 js/css 文件或改了 template/，必须跑构建
node tools/build-index.js

# 4. 提交
git add -A
git commit -m "docs: 申报书主体与技术说明书大纲"

# 5. 推送
git push -u origin feat/p1-申报书初稿
```

然后去 GitHub 网页点 **`Compare & pull request`** → **`Create pull request`**。

> 你是兜底审核人，很多情况下**你自己合并就行**。
> 但涉及 `tools/` `template/` 的改动，最好拉 P2 或 P3 一起看一眼，四只眼睛比两只强。

**用 GitHub Desktop 更省事**：
```
Branch → New branch → 改文件 → 左下角填摘要 → Commit → Publish branch
→ 网页出现黄色提示条 → Compare & pull request
```
