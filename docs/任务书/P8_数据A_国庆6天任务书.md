## 七、怎么提交到 GitHub

**Desktop 路线**：
```
Branch → New branch
分支名：feat/p8-data-院校数据
→ 改 js/01 或 js/02
→ Summary 填：feat(data): 更新福建10所院校2024录取数据
→ Commit → Publish branch
→ Compare & pull request → Create pull request
（系统自动把 P9 加为审核人）
```

> ⚠️ **改数据文件不用跑构建**（只是改内容，没新建文件）。
> 改完直接在浏览器打开 `index.html` 看效果即可。

**网页路线**（国庆在外）：见 `docs/17` 路线 B。

> 💡 **数据改动的建议**：一次 PR 改一所学校的数据，别一口气改十所。
> 万一某一所错了，回退起来容易得多。
