## 六、怎么提交到 GitHub

**Desktop 路线**：
```
Branch → New branch
分支名：feat/p6-trust-凭证校验
→ 改 js/05 17 26 或 css/14
→ Summary 填：feat(trust): 增加内容哈希存证
→ Commit → Publish branch
→ Compare & pull request → Create pull request
（系统自动把 P7 加为审核人）
```

> ⚠️ **如果你新建了 `js/27-xxx.js`，必须跑构建**：
> ```bash
> node tools/build-index.js
> ```
> 不跑的话新文件不会被加载，你会以为自己写错了。

**网页路线**（国庆在外）：见 `docs/17` 路线 B。
