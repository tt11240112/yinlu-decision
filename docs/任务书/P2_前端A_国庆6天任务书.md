## 六、怎么提交到 GitHub

**路线 A · GitHub Desktop（推荐）**
```
1. 打开 Desktop，确认当前分支显示 v3
2. Branch → New branch
   分支名：feat/p2-mobile-适配的页面名
   例如：feat/p2-mobile-navbar
3. 改你的 css / js 文件
4. 回到 Desktop，左下角 Summary 填：
   style(css): 修复手机上导航溢出
5. 点 Commit to ...
6. 点 Publish branch
7. 网页出现黄色提示条 → Compare & pull request
8. 标题填同样的内容，勾选模板里的 7 条自检
9. Create pull request
   （系统会自动把 P3 加为审核人）
```

**路线 B · 网页直接改（国庆在外、没带電腦）**

详见 `docs/17` 的路线 B。要点：
```
1. github.com 打开仓库，确认左上角是 v3（不是就切）
2. 找到你要改的文件，点铅笔图标
3. 改内容
4. 拉到最下面，选第二项 Create a new branch...
5. Propose changes → Create pull request
```

> ⚠️ **只改你认领的 9 个文件。** 改了别人的，PR 会自动找别人审，
> 很可能被打回。要改别人的，**先找 P1 或那个人说一声**。
