## 五、佐证材料 PDF 怎么做

> 通知要求：**一个 PDF + 有目录 + 分类或按重要性排序。**

### 建议的目录结构

```
佐证材料_引路_20261003.pdf
├── 封面：项目名称、学校、团队成员
├── 一、作品概览
│     首页全屏截图 / 技术栈 / 核心功能一览
├── 二、功能截图（按重要性排序）
│     ① 高考志愿筛选（核心）
│     ② 院校对比
│     ③ 决策日历
│     ④ 问答社区
│     ⑤ 可信经验分享 ← 这是我们最独特的功能，放前面点
│     ⑥ 电子宠物 / 主题切换
├── 三、系统设计
│     系统架构图 / 数据流图 / 数据库表结构（P9 给）
├── 四、可信与安全
│     匿名凭证流程图 / 威胁模型图（P6 P7 给）
├── 五、数据说明
│     院校数据样本表（P8 给）
└── 六、其他佐证
      软著申请受理截图 / 成员分工与贡献说明
```

### 制作工具（选一个）

| 工具 | 怎么用 | 推荐度 |
|---|---|---|
| **Word → 另存为 PDF** | 最省事。把截图插入 Word，排好版，插入自动目录，另存 PDF | ⭐⭐⭐ 推荐 |
| PowerPoint → 另存为 PDF | 每页一张图 + 说明文字，适合全是截图的情况 | ⭐⭐ 可选 |
| Adobe Acrobat 合并 | 把多个 PDF 拼成一个 | ⭐ 备选 |

**Word 自动目录怎么做**（这一步很多人不会）：
```
1. 把每个一级标题选中 → 开始菜单 → 样式 → 选"标题 1"
2. 二级标题选"标题 2"
3. 光标点到封面后面
4. 引用 → 目录 → 选"自动目录 1"
5. 完成！目录自动生成
6. 文件 → 另存为 → 保存类型选 PDF
```

> 🔴 **最后再检查一次：页数、目录能不能点到对应页。**
> 合并完成后**必须用 PDF 阅读器打开看一遍**，
> 确认不是一堆图叠在一起。

## 七、怎么提交到 GitHub

**截图和 PDF 文件比较大，注意：**

| 情况 | 怎么办 |
|---|---|
| 单个文件 < 25 MB | GitHub 网页能直接上传 ✅ |
| 单个文件 > 25 MB | ⚠️ **不要传！** 改成压缩或降低分辨率 |
| PDF > 50 MB | 用 Word 重新导出时选"最小文件大小"，或压缩图片 |

**上传截图到 GitHub 的最简方法**（不用命令行）：
```
1. 打开 github.com 上的仓库，确认分支是 v3
2. 点进 docs/佐证材料/ 文件夹
   （如果文件夹还不存在，先 Add file → Create new file，
     文件名填 docs/佐证材料/README.md，内容随便写点，提交）
3. 点右上角 Add file → Upload files
4. 把图片拖进去
5. 拉到下面，选第二项 Create a new branch...
6. Propose changes → Create pull request
```

**代码改动走 Desktop 路线**（同 P2 任务书第六节）：
```
Branch → New branch → 分支名 feat/p3-视觉调整
→ 改文件 → Commit → Publish branch → Compare & pull request
```
