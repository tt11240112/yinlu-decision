## 三、🔴 必看：一个会浪费你半天的坑

> **`js/16` 和 `js/18` 里的家庭相关函数是死代码，改了没有任何效果。**

具体是这三个函数：

| 函数 | 在哪个文件 | 实际生效的是 |
|---|---|---|
| `renderFamily` | `js/16-feature-compare.js` | **`js/26-family-override.js`（P6 负责）** |
| `generateFamilyInvite` | `js/18-feature-actions.js` | 同上 |
| `joinFamilyInvite` | `js/18-feature-actions.js` | 同上 |

**原因**：`js/26-family-override.js` 是**最后加载**的文件，它会覆盖前面同名的函数。

```
所以：改 js/16 里的 renderFamily  → 没反应（被 26 号盖掉了）
      改 js/26 里的 renderFamily  → 才有效
```

> 💡 **怎么避免踩坑**：改任何函数之前，先在 VS Code 里按 `Ctrl + Shift + F`
> 全局搜一下函数名。**如果出现两次以上**，说明有覆盖关系，别改错文件。

**家庭功能的改动找 P6 商量**（文件归他），别自己改 `js/26`。
