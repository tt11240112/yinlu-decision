### 🔴 第五章「创新点」怎么写（最重要的一节）

> 评委看申报书，**先看这一章**。写不好，后面写得再细也没人看。

**三条创新点的模板**（照着改，别照抄）：

```
创新点一：把"可信"做成了技术能力，而不是口号
    现有同类产品无法验证分享者的真实身份，导致经验真假难辨。
    本项目提出基于匿名凭证的方案，在保护隐私的前提下
    证明"分享者确为本校在校生"，并通过哈希存证保证内容未被篡改。

创新点二：面向决策过程而非查询过程
    同类产品多为"查分数—查院校"的查询工具。
    本项目围绕"如何选择"设计决策日历、多方案对比、
    家庭协同等流程性功能，覆盖决策的完整链路。

创新点三：轻量化架构，零依赖部署
    采用原生技术栈，无需构建工具与服务器即可运行，
    全站可打包为单文件离线使用，显著降低了在偏远地区的传播成本。
```

### Word 自动生成目录的操作（P3 会做到，你验收用）

```
1. 选中一级标题 → 开始 → 样式 → 「标题 1」
2. 选中二级标题 → 样式 → 「标题 2」
3. 光标点到封面后面
4. 引用 → 目录 → 「自动目录 1」
5. 文件 → 另存为 → 保存类型选「PDF」
```

### 🔴 验收清单（Day 6 早上逐条打勾）

```
□ 是【一个】PDF 文件，不是多个散文件
□ 有自动生成的目录
□ 目录页码能点到对应页（不是死的）
□ 按重要性排过序（核心功能在前）
□ 文件大小在邮件附件限制内（一般 < 20MB 最保险）
□ 每一页都不是空白、没有图叠图
□ 学校名、人名没有错别字
□ 图片清晰，没有拉伸变形
```
