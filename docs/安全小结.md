## 四、答辩常见提问的应答（提前准备好）

| 评委可能问 | 你们怎么答 |
|---|---|
| 「凭什么说你们的信息可信？」 | 讲认证标识 + 来源标注 + 发布时间三部分（详见 P6 的信任设计） |
| 「数据存在浏览器里，安全吗？」 | 诚实：这是演示形态的限制，并讲 B 档的后端方案 |
| 「密码怎么存的？」 | 讲 SHA-256+盐，并主动说明"已识别该方案需升级为 PBKDF2，方案已完成设计" ⭐ **主动承认反而加分** |
| 「有没有考虑 XSS？」 | 讲 `escapeHtml` / 外链白名单，并说明迁移后端后的输入校验设计 |
