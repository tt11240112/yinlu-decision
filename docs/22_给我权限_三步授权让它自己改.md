## 一、我要的东西叫 PAT

全称 Personal Access Token，可以理解成**一把临时钥匙**。

它不是你的密码。区别在这儿：

| | 你的密码 | PAT 令牌 |
|---|---|---|
| 能改你的登录邮箱吗 | 能 | **不能** |
| 能删你的仓库吗 | 能 | **看你勾什么**（我们只勾仓库） |
| 能过期吗 | 不能 | **能，你自己定 7 天** |
| 能单独吊销吗 | 不能 | **能，点一下就作废** |

所以比直接给密码安全得多。

## 二、三步操作

### 第 1 步 · 打开生成页面

浏览器打开这个网址（**复制粘贴到地址栏回车**）：

```
https://github.com/settings/tokens
```

打开后有两种可能：
- 看到 **Tokens (classic)** 字样 → 走【方式 A】
- 看到 **Fine-grained tokens** 新版界面 → 走【方式 B】

---

## 方式 A · Tokens (classic)（推荐，更简单）

### 第 2 步 · 点生成按钮

页面上找这个按钮：

```
[ Generate new token ]              ← 点它
      └─ 弹出小菜单，选：
         [ Generate new token (classic) ]
```

> ⚠️ 认准 **classic** 这个词，别选错。

然后按要求填三个字段：

| 字段 | 填什么 | 说明 |
|---|---|---|
| **Note（备注）** | `引路-临时授权-7天` | 随便写，将来好认出是哪把钥匙 |
| **Expiration（有效期）** | **`7 days`** | ⚠️ 别选 30 天，更别选 No expiration。7 天足够我用完 |
| **Select scopes（权限）** | **只勾 `repo` 一个大项** | 见下面 |

**权限这一屏最容易出错，仔细对照：**

```
☑ repo                          ← 只勾这一个！它下面的子项会自动跟着勾上
    ☑ repo:status
    ☑ repo_deployment
    ☑ public_repo
☐ workflow                      ← 不勾
☐ write:packages                ← 不勾
☐ read:packages                 ← 不勾
☐ admin:org                     ← 不勾
☐ delete_repo                   ← 🔴 绝对不勾！勾了这种级别的钥匙一旦泄露，仓库能被直接删掉
☐ user                          ← 不勾
（下面还有一堆，全部保持不勾）
```

> 🔴 **`delete_repo` 一定别勾。** 勾了它，一把钥匙就能删掉你的整个仓库。

### 第 3 步 · 生成并复制

滚到页面最底部，点：

```
[ Generate token ]              ← 绿色按钮
```

页面会跳出一串字符，长这样：

```
ghp_abCdEfGhIjKlMnOpQrStUvWxYz0123456789
```

**点右边那个小方块图标复制它。**

## 方式 B · 新版 Fine-grained tokens 界面

新版界面也能用，只是勾法不同：

1. 点 `Generate new token`
2. **Token name** 填：`引路-临时授权-7天`
3. **Expiration** 选最短的那个（一般是 `7 Days` 或 Custom）
4. **Repository access** → 选 **`Only select repositories`**
   → 下面下拉框里**只选 `yinlu-decision` 这一个**
   > ⚠️ 千万别选 All repositories
5. **Permissions** → 点开 `Repository permissions`，找到这几项：

| 权限项 | 设成 |
|---|---|
| Administration | **Read and write** ← 改默认分支、加分支保护靠它 |
| Contents | **Read and write** |
| Pull requests | Read and write |
| Metadata | Read only（一般默认就是） |

6. 点 `Generate token`，复制那串字符

**复制好之后，直接粘到对话框里发给我就行**，不用加任何说明。

我会立刻做这几件事，每一步都打印出来给你看：

```
① 确认令牌有效 + 告诉我它属于哪个账号
② 把默认分支 main → v3
     队友 clone 下来直接是新版，不会拿到旧的三个大文件

④ 冻结 main
     旧版大文件留着保底，谁都改不了
⑤ 顺手把 8 个队友的用户名列出来
```

**正式执行前我会先跑一次「只看不改」的检查模式**，让你确认过再动手。

## 四、用完一定要吊销

我这边事情做完之后，**请你立刻回到这个页面把它删了**：

```
https://github.com/settings/tokens
```

在令牌那一行右侧找 **`Delete`**（红色字），点一下 → 确认。

> 删掉之后钥匙立刻失效，就算泄露出去也没用了。
> **这跟改密码是两回事** —— 吊销令牌不影响你正常登录，也不影响队友。

## 附录：不想给令牌，自己动手的对照表

完全支持。这四件事在网页上点也只要 5 分钟：

| 要做的 | 在哪点 |
|---|---|
| **改默认分支** | 仓库 `Settings` → 左侧 `Branches` → Default branch 右边的 ↔ 图标 → 选 `v3` → `Update` → 弹窗里点 `I understand` |
| **给 v3 上锁** | 同一页，`Add branch protection rule`（老界面）或 `Add branch ruleset`（新界面）→ pattern 填 `v3` → 勾 `Require a pull request before merging` → 勾 **`Require review from Code Owners`** → Required approvals 填 `1` → **务必别勾** Require status checks → `Create` |
| **冻结 main** | 同上，再加一条规则，pattern 填 `main` |
| **抄队友用户名** | 仓库 `Settings` → `Collaborators`，那一列就是用户名（不带 `@` 符号） |

> 完成后喊我一声，我帮你验收；或者直接让队友发一次「练手 PR」，那是最实在的验证。
