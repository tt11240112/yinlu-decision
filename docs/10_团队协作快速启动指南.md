## 三、工作流程（每个人都要遵守）

### 第一周：Git 基础训练

```bash
# 1. 克隆仓库（只做一次）
git clone https://github.com/你的用户名/yinlu-decision.git
cd yinlu-decision

# 2. 创建自己的分支（用你的名字）
git checkout -b feat/xiaoming-gaokao-filter

# 3. 开始改代码
# 只改你负责的文件！

# 4. 提交代码
git add js/home.js          # 只add你改的文件
git commit -m "feat: 添加决策卡片切换动画"

# 5. 推送到 GitHub
git push -u origin feat/xiaoming-gaokao-filter

# 6. 在 GitHub 网页上提 PR
# 打开 GitHub → Pull requests → New pull request
# base: main ← compare: feat/xiaoming-gaokao-filter
# 写清楚改了什么 → Create pull request

# 7. 等 G0 或队友 Approve → 合并
```

完整教程：`docs/06_改代码到提交GitHub完整流程.md`

## 五、核心规则（打印贴桌上）

### ⛔ 绝对不能做的 3 件事

1. ❌ **不要直接改 main 分支**
   ```bash
   # 错误示范
   git checkout main
   git add .
   git commit -m "改了代码"
   git push
   # ❌ 这样会被 GitHub 拒绝！
   ```

2. ❌ **不要改别人负责的文件**
   - G1 的人不要改 `js/questions.js`（那是 G3 的）
   - 看不清谁负责啥？查 `docs/02_9人分工与文件认领表.md`

3. ❌ **不要用 `git add .` 全部添加**
   ```bash
   # 错误示范
   git add .        # ❌ 可能把不该提交的文件也加进去
   
   # 正确做法
   git add js/home.js   # ✅ 只加你改的文件
   ```

### ✅ 必须做的 3 件事

1. ✅ **每天拉一次最新代码**
   ```bash
   git checkout main
   git pull origin main
   git checkout dev-你的名字
   git merge main        # 把 main 的更新合并到你的分支
   ```

2. ✅ **提交前先检查**
   ```bash
   git status           # 看看你改了哪些文件
   git diff             # 看看具体改了什么
   # 确认无误再 commit
   ```

3. ✅ **PR 标题要写清楚**
   ```
   ❌ 错误：更新了代码
   ❌ 错误：fix bug
   ✅ 正确：feat(home): 添加决策卡片切换动画
   ✅ 正确：fix(filter): 修复地区筛选点击无效的问题
   ```

## 六、常见问题（新手必看）

### Q1: 我不小心改了别人的文件怎么办？

```bash
# 还没 commit：撤销修改
git checkout -- js/questions.js

# 已经 commit：撤销最后一次提交
git reset HEAD~1
```

### Q2: 我的分支落后 main 很多次提交，怎么办？

```bash
git checkout main
git pull origin main
git checkout dev-你的名字
git merge main
# 如果有冲突，手动解决后再 commit
```

### Q3: PR 被拒绝了，说有冲突？

说明别人改了同一个文件。解决方法：
```bash
# 1. 更新 main
git checkout main
git pull origin main

# 2. 合并到你的分支
git checkout dev-你的名字
git merge main

# 3. 手动解决冲突
# 打开有冲突的文件，找到 <<<<<<< 和 >>>>>>> 标记
# 删掉标记，保留正确的代码

# 4. 重新提交
git add .
git commit -m "merge: 解决与 main 的冲突"
git push
```

### Q4: 我想撤销刚才的 commit？

```bash
# 撤销最后一次 commit，但保留修改
git reset HEAD~1

# 撤销最后一次 commit，并删除修改（危险！）
git reset --hard HEAD~1
```

### Q5: 我不小心把代码提交到 main 了？

立即联系 G0，千万不要 push！
