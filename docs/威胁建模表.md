## 📖 通俗理解

**威胁建模 = 假设你是黑客，列出所有能搞破坏的办法，然后逐个堵上。**

评委看安全类作品，一定会问：「你想过哪些攻击？怎么防的？」
**这份表就是答案。**

## 建模方法：STRIDE（照着六个方向想）

> 每个字母一类攻击。一行一条威胁，照格式填。

| 字母 | 威胁类型 | 一句话解释 |
|---|---|---|
| **S** | Spoofing 仿冒 | 假装成别人 |
| **T** | Tampering 篡改 | 偷偷改数据 |
| **R** | Repudiation 抵赖 | 干了不认账 |
| **I** | Information Disclosure 信息泄露 | 看到不该看的 |
| **D** | Denial of Service 拒绝服务 | 把服务搞瘫 |
| **E** | Elevation of Privilege 提权 | 普通用户拿到管理员权限 |

## 重点攻击面提示（想不出来就从这里挑）

```
□ localStorage 全部可信？（用户按 F12 就能改，纯前端没有真正的安全可言）
□ 问答区能不能灌垃圾内容 / 刷屏？
□ 用户上传头像，能不能传恶意文件？
□ 经验分享里有没有 XSS 风险？（输入 <script> 试试）
□ 家庭邀请码 YL-XXXXXXXX 能被猜出来吗？能枚举吗？
□ 有没有频率限制？（能不能一秒请求一万次）
□ 别人能不能看到其他用户的收藏/浏览历史？（纯本地，换账号其实看不到，迁移到后端后是重点）
□ 经验内容能不能被篡改后声称"我早就说过"？
```
