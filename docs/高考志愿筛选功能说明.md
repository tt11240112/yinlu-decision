# 高考志愿筛选功能说明

负责人：P4 业务 A。版本：2026-10-02。基于提交给助手的项目文件快照实现，尚需安装到本地分支、P5 互审和 P1 合并。

## 功能与交互

院校库支持学校名称、专业名称 / 学科门类、学校所在地、办学层次，以及基于录取记录的招生科类、录取批次、生源省份和年份组合查询。学校所在地用于找城市中的学校，生源省份用于匹配考生报考省份。条件之间取交集；专业名与门类需命中同一个专业，录取条件需命中同一条记录。

地区选择兼容省市简称和完整名称，直辖市支持简称，城市匹配同时核对省份。补齐原来被城市后缀过滤掉的地区选项，例如平潭综合实验区。切换首页院校任务入口时重置旧查询，避免旧条件让新任务看似没有数据。

院校排序提供相关度、校名和最近更新。相关度优先学校全名匹配、其次前缀匹配，同分保留原数据顺序；不是大学排名。最近更新使用 updatedAtISO，缺失日期排后。清空操作恢复所有院校筛选和默认排序。无匹配时提供清空入口；缺录取数据时明确提示数据待补充。

院校卡片进入对应详情，错误 ID 显示资料不存在，不再自动展示第一所学校。可选字段缺失时显示待补充。专业搜索支持名称、学院、门类及说明。录取详情按年份、生源省份、科类查询记录，展示批次、专业组 / 专业、最低分、最低位次、计划数与来源；零值和缺失值区别显示，表格在窄屏内横向滚动。

## 文件与实现

| 文件 | 改动 |
|---|---|
| js/13-feature-filters.js | 独立院校筛选状态、组合谓词、稳定排序、新控件及详情事件 |
| js/14-feature-picker.js | 地区归一化、省市匹配、专业选项、任务入口重置 |
| js/15-feature-render.js | 卡片与详情容错、真实记录查询、空状态、结果刷新 |
| css/03-filters.css | 新增控件的网格、窄屏布局与焦点样式 |
| css/09-card-layout.css | 录取表局部滚动及布局；移除原文件尾部孤立加号 |

沿用项目的普通 script 顺序，13 → 14 → 15 在引导初始化前加载。新控件挂载到现有院校筛选栏，无需改 index.html 或运行构建。清空采用捕获阶段先重置新增状态；专业门类点击等原有事件完成后，在下一任务刷新结果。详情专业输入使用 P4 自有 ID，避免原处理器直接访问缺失数组。没有新运行时依赖，没有改动其他组的数据或事件文件。

## 验证与数据边界

自动检查覆盖名称搜索、地区、专业门类、层次、组合记录条件、空状态、缺字段、错误 ID、文本转义和时间边界；具体结果见 p4-filter-review.md 及交付包验证记录。另使用 Chromium 检查桌面、手机界面和实际点击流程。

当前上传的数据是 3 所示例学校，未收录真实 admissionRecords。院校基础筛选可以演示；科类、批次等真实招生条件需要 P8 按《院校数据字段清单》接入数据。旧下拉选项不会被当作真实招生依据。本次没有实现选科资格判定、录取概率、冲稳保算法、官方报名或真实账户后端。
