## 接入约定

数据继续由 P8 维护 `js/02-data-institutions.js` 中的 `institutions` 数组。本次 P4 没有修改数据文件。保留现有 `id`、`school` 和驼峰字段；任务书中的 `school_id`、`school_name`、`subject_type` 等是模板名，不能直接替换现有字段。新增录取数据放在各院校的 `admissionRecords` 数组。

目前只有 3 所示例院校，没有可用于查询的真实录取记录。原来的 `admissionSubjects`、`admissionYears`、`admissionProvinces` 是展示选项，不能据此推断学校招生资格。

| 字段 | 类型 | 要求 | 使用方式 |

| school | string | 必填 | 学校全称，搜索与显示 |
| province | string | 建议必填 | 学校所在地，推荐使用福建省等完整名称 |

| educationLevel | string | 兼容旧数据 | 如 本科 / 研究生教育；没有 levels 时用于层次过滤 |
| type / intro | string | 建议提供 | 类型与简介，不用于推断招生批次 |
| officialUrl / officialSource | string | 建议提供 | 官网 http(s) 链接及来源名称 |
| updatedAtISO | string | 建议提供 | ISO 日期，供最近更新排序，缺失排后 |
| updatedAt | string | 建议提供 | 面向用户的更新时间文字 |
| majors | string[] | 兼容字段 | 重点关注专业名；与 majorPrograms 合并去重 |

`englishName`、`founded`、`campuses`、`officialSummary`、`admissionBrief`、`dataSummary`、`campusSummary`、`careerSummary`、`dataSource`、`dataUrl` 继续兼容。`admissionResources`、`latestUpdates`、`campusDetails`、`cityReferences`、`campusMedia` 和 `postgraduateRecommendation` 保留原结构；未提供时显示待补充，不要求为了渲染而编造内容。

## 录取记录 admissionRecords

每一条记录都对应一个明确统计口径。学校所在地与考生生源省份是两个不同概念。

| 字段 | 类型 | 要求 | 说明 |
|---|---|---|---|
| year | integer | 必填 | 录取年份；前端接收 1900–2100 的整数 |
| province | string | 必填 | 考生生源省份，推荐完整名称 |
| subjectType | string | 必填 | 物理类、历史类、理科、文科等原始口径 |
| batch | string | 必填 | 本科批、本科提前批等，按当年当地官方名称 |
| groupCode | string | 有专业组时填写 | 保留前导零，不用数字类型 |
| majorName | string | 专业粒度时填写 | 不能将院校汇总线冒充专业线 |
| minScore | integer 或 null | 有来源时提供 | 非负；缺失为 null，不能用 0 代替未知 |
| minRank | integer 或 null | 重点字段 | 正整数，需明确同省同科类同年份口径 |
| planCount | integer 或 null | 有来源时提供 | 非负；0 与未知有不同含义 |
| sourceUrl | string | 必填 | 对应记录原始 http(s) 页面，不用无关主页代替 |
| sourceName | string | 建议必填 | 发布机构 / 页面标题 |
| fetchedAt | string | 建议提供 | 采集或核验时间，ISO 日期 |
| statisticScope / note | string | 建议提供 | 统计范围、特殊限制；当前表格未单独展示 |

缺少年份、省份、科类、批次或 http(s) 来源链接的记录不参加筛选。前端检查只是格式检查，不代表来源真实性已经核验。P8 应核对原始出处，并对相同年份、省份、科类、批次、专业组和专业的重复记录去重。请不要将不同粒度的分数拼接成一条记录。

科类、批次、生源省份和年份必须同时命中同一条记录。当前版本支持这四个维度及来源展示；尚未解析选科组合限制，也没有录取概率、冲稳保或报名提交功能。

## 专业 majorPrograms

| 字段 | 类型 | 要求 / 说明 |
|---|---|---|
| name | string | 必填，专业名称 |
| category | string | 建议必填，工学、文学、农学等门类 |
| school | string | 所属学院，沿用现有命名 |
| level | string | 专业层次 |
| note | string | 培养说明，保留来源依据 |
| officialUrl | string | 学院或专业官方 http(s) 页面 |
| code | string | 建议后续补充专业代码，保留前导零；当前不参与筛选 |
| tuition | integer 或 null | 建议后续补充年学费，明确币种、年度；当前未展示 |

专业名与门类必须匹配同一专业条目。旧 majors 数组仍兼容，但没有可靠门类映射时不会猜测门类。

## P8 接入检查

1. 保留原来的 id 和 school；先给一所学校补齐带来源的 admissionRecords。
2. 打开院校库，选择这条记录对应的科类、批次、生源省份和年份，应能找到该学校。
3. 换成不匹配的组合，应显示暂无匹配；不要把空结果理解为学校不招生。
4. 进入详情，切换年份、省份、科类，核对表格和来源。
5. 发布前由团队复核真实资料。测试脚本里的虚构学校与 example.test 链接只存在内存中，不能复制到正式数据。
