# 引路网站原型

这是「引路」项目的可运行前端原型，按照项目书中的产品逻辑制作：

- 高考志愿、考研择校、职业选择、大学适应四个决策阶段
- 认证经验库、按维度筛选和搜索
- 后台实名、前台匿名的身份信任表达
- 匿名提问与认证回答匹配
- 学生/家长家庭决策空间
- 候选学校对比和认证中心

## 运行

直接双击 `index.html` 即可查看。若希望使用本地服务，在 `小挑` 文件夹运行：

```powershell
python -m http.server 4173
```

然后打开：`http://localhost:4173/引路网站/`

## 说明

当前是产品概念原型，不代表平台已经正式上线。页面内的学校、经验和数据均为展示产品交互所用的示例内容，正式开发时需要接入真实调研数据、身份核验、内容审核和后端存储。
