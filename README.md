# 引路网站：完整试用版

这是「引路」的前端试用版源代码，单独存放在本目录，和之前的“引路网站”原型互不影响。

## 已实现

- 高考志愿、考研择校、职业选择、大学适应四个决策阶段
- 认证经验库、搜索、筛选和同高中优先排序
- 注册、登录、退出和个人资料修改
- 匿名提问，以及“我的问题”列表
- 学校/专业候选收藏和对比
- 家庭关联邀请码生成与复制
- 校园身份认证申请状态
- 刷新页面后保留试用数据
- 响应式布局，支持手机浏览

## 运行

在本目录运行：

```powershell
python -m http.server 4173
```

然后打开：`http://localhost:4173/`

也可以直接双击 `index.html` 浏览，但使用本地 HTTP 服务更稳定。

## 重要说明

这是前端试用版，不是真实的多用户账号系统。账号、密码、问题、收藏、邀请码和认证申请仅保存在当前浏览器的 `localStorage` 中：

- 换浏览器、换设备或清理浏览器数据后，记录不会同步
- 账号密码不应填写真实敏感信息
- 认证申请只是产品流程演示，不会连接真实身份核验
- 页面内学校、经验和数据是产品展示用示例，正式上线前需要接入后端数据库、短信/邮箱认证、身份核验、内容审核和权限控制

后续要做成真正可供多人使用的平台，需要再增加后端服务和数据库；当前目录可以直接作为 GitHub Pages 的静态试用版源码。
